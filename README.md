# A Unified Framework for Thumbnail Analysis, Prediction, and Generation

A Django-based web application that combines thumbnail analysis, CTR prediction, heatmap visualization, text detection, and AI-assisted thumbnail generation.

## Features

- **Thumbnail Analysis:** Evaluates image quality, brightness, contrast, and visual composition.
- **CTR Prediction:** Estimates the potential click-through performance of thumbnails.
- **Heatmap Visualization:** Highlights important regions, hotspots, and subject focus.
- **Text Detection:** Extracts text from thumbnails using OCR.
- **AI Analysis:** Provides thumbnail insights and improvement suggestions using Google Gemini.
- **Thumbnail Generation:** Generates thumbnails from text prompts using Cloudflare AI.
- **Thumbnail Builder:** Creates customized thumbnails with headlines, prompts, and aspect ratios.
- **User Authentication:** Supports user registration and login.
- **My Collection:** Saves and manages generated thumbnails.
- **Download:** Allows users to download generated thumbnails.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Django
- **Database:** SQLite
- **Image Processing:** OpenCV, Pillow, NumPy
- **OCR:** Tesseract OCR, Pytesseract
- **AI Services:** Google Gemini API, Cloudflare AI
- **Deployment:** Render, Docker
- **Version Control:** Git, GitHub
